# Projects

Three practical jobs from the course, each implemented several ways. Pick a job, read its README, then open any implementation folder in Android Studio.

| Job | Implementation | Idea | Kotlin files | Lines |
|---|---|---|---|---|
| Job 1 | [Packaged](job-1-product-listing-rest/v1-packaged/) | Separated network layer | 6 | 164 |
| Job 1 | [Compact](job-1-product-listing-rest/v2-compact/) | Assessment-ready, minimal files | 4 | 157 |
| Job 2 | [Room](job-2-user-profile-sqlite/v1-room/) | Room on top of SQLite | 10 | 330 |
| Job 2 | [SQLiteOpenHelper](job-2-user-profile-sqlite/v2-sqlite-helper/) | Plain SQLite with no extra libraries | 10 | 399 |
| Job 3 | [MVVM packages](job-3-location-sharing-firebase/v1-mvvm-packages/) | Model, repository, viewmodel, ui | 11 | 579 |
| Job 3 | [Flat](job-3-location-sharing-firebase/v2-flat/) | Everything in one package | 10 | 451 |
| Job 3 | [View layer](job-3-location-sharing-firebase/v3-view-layer/) | model, repository, view, viewmodel | 13 | 604 |
| Job 3 | [Styled](job-3-location-sharing-firebase/v4-styled/) | Polished UI with coroutines | 13 | 878 |

Folders named `v1`, `v2`... are complete Gradle projects. The `docs/` folder inside each job holds the specification, the AI-agent prompt and the specification page images.
